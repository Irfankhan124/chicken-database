# Chicken Database ERP

دا د افغانستاني کاروبارونو لپاره د پښتو، RTL، Next.js + Supabase + Firebase Hosting ERP سټارټر پروژه ده.

## Setup
1. `npm install`
2. `.env.local.example` to `.env.local`
3. Supabase SQL from `supabase/schema.sql` run in Supabase SQL editor
4. `npm run dev`
5. Firebase deploy: `npm run build` then `firebase deploy`
